# 90-day organic-search scorecard

## Scope and denominator

The traffic-page denominator is 46: the home page, `/tools/`, 30 tool-detail pages, six category pages, four comparison pages, and four guides. Trust and legal pages are deliberately outside this traffic KPI.

Record launch-day values only after the site is live and the authorized analytics and Search Console setup is complete. “Non-brand” excludes searches for the site name and its close variants. “Monthly organic clicks” means the latest available 28-day Search Console total; label an early launch snapshot as partial in Owner / notes.

## Review rules

- If the indexed rate is low, check crawling, canonical URLs, duplicate content, page quality, and internal links.
- If pages are indexed but do not receive impressions, improve keyword intent and strengthen the category that most closely matches search demand.
- If impressions exist but click-through is low, improve titles, descriptions, and the promise made in search results.
- If qualified clicks and sustained traffic reach tool-detail pages, expand the corresponding leading category with comparisons and guides.
- If there is still almost no non-brand exposure at day 90, narrow focus to the strongest category and pause horizontal expansion.
